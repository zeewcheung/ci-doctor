# Security policy

Do not place vulnerability details, exploit steps, secrets, private code, logs, customer data, credentials, internal URLs, or attachments in a public Issue or Discussion.

The repository owner should enable GitHub private vulnerability reporting. Until that private channel exists, sensitive vulnerability reports cannot be accepted. The ordinary CI request Issue Form is only for non-sensitive metadata; do not use it for a vulnerability report.

CI Doctor is a heuristic diagnostic utility, not a security scanner, security certification, or guarantee. Never test it against a repository you do not own or have explicit authorization to assess.
